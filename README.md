# A little closer to home

A small, phone-friendly study companion for the days leading up to October 22, 2026.

## Preview

Open index.html in a browser, or serve this folder locally (for example, python3 -m http.server 8000) and visit http://localhost:8000. Google Fonts are optional; system fallbacks are provided.

## Personalize it

- Daily Boost lines: edit the BOOSTS array near the top of scripts/main.js. Tap the card to cycle lines.
- Countdown date: change the EXAM_DATE constant at the top of scripts/main.js.
- Signature: replace Kamran in the footer of index.html.
- Sharing: bookmark the link or add it to her phone home screen. noindex, nofollow asks search engines not to index it, but does not password-protect a public URL.

## Progress and privacy

Day markers and today's page tally use this browser's localStorage; they are device/browser-specific and do not sync. The tally resets automatically each local calendar day. To reset saved data, remove the keys closer-home-days-v1, closer-home-tally-v1, and closer-home-tally-date-v1 in browser developer tools.

There are no analytics or trackers. Google Fonts are the only external requests. Reduced-motion preferences disable decorative animations and confetti; controls still work.
